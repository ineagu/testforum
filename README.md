# Tab Content Hider

A simple Chrome extension that hides the current tab content with a single click.

## Features

- Click the extension icon to hide the entire page content
- Click again to show the content
- Works on any webpage

## Installation

1. Download or clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in the top right)
4. Click "Load unpacked"
5. Select the folder containing this extension

## Usage

1. Navigate to any webpage
2. Click the extension icon in your Chrome toolbar
3. The page content will be hidden
4. Click the icon again to show the content

## Files

- `manifest.json` - Extension configuration
- `background.js` - Handles the extension icon click event
- `icon16.png`, `icon48.png`, `icon128.png` - Extension icons
