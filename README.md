# testforum

A simple landing page for the TestForum Extension.

## About

This is a clean, modern website designed to showcase the TestForum browser extension. The site includes:

- Hero section with call-to-action
- Features showcase
- About section
- Download section for multiple browsers

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive design
- `script.js` - Interactive features and smooth scrolling

## Usage

Simply open `index.html` in your browser to view the site. No build process or dependencies required.

## Features

- Responsive design that works on mobile and desktop
- Smooth scrolling navigation
- Interactive buttons
- Modern gradient design
- Animated elements on scroll
